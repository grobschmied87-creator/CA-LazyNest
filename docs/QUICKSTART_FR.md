# Démarrage rapide – CA LazyNest

## Prérequis
- Autodesk Fusion (Windows recommandé)
- Repo / ZIP extrait

## Installation
1. **Fermer** Fusion.
2. Double-cliquer `INSTALL.bat` (ou lancer `install.ps1`).
3. Ouvrir Fusion → **Utilitaires → Modules complémentaires**.
4. Sélectionner **LazyNest** → **Exécuter** / démarrage auto.

Chemin : `%APPDATA%\Autodesk\Autodesk Fusion 360\API\AddIns\LazyNest`

## Premiers pas
1. Sélectionner les pièces (ou charger un projet).
2. Ouvrir la palette **CA LazyNest**.
3. Régler stock/matériau, écarts, options.
4. Imbriquer → vérifier → **Appliquer** (CAM optionnel).
5. ⓘ = info, diagnostic, don.
