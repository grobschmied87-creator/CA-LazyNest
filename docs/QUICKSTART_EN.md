# Quick start – CA LazyNest

## Requirements
- Autodesk Fusion (Windows recommended)
- This repo / ZIP extracted

## Install
1. **Quit** Fusion.
2. Double-click `INSTALL.bat` (or run `install.ps1` in PowerShell).
3. Start Fusion → **Utilities → Add-Ins → Scripts and Add-Ins**.
4. Select **LazyNest** → **Run** / enable Run on Startup.

Manual path: `%APPDATA%\Autodesk\Autodesk Fusion 360\API\AddIns\LazyNest`

## First steps
1. Select parts in the design (or load a project).
2. Open the **CA LazyNest** palette.
3. Set stock/material, spacing, options.
4. Nest → review → **Apply** (optional CAM).
5. ⓘ = info, diagnostics, donate.
