# Guía rápida – CA LazyNest

## Requisitos
- Autodesk Fusion (Windows recomendado)
- Repo / ZIP descomprimido

## Instalación
1. **Cerrar** Fusion.
2. Doble clic en `INSTALL.bat` (o ejecutar `install.ps1`).
3. Abrir Fusion → **Utilidades → Complementos → Scripts y complementos**.
4. Seleccionar **LazyNest** → **Ejecutar** / inicio automático.

Ruta: `%APPDATA%\Autodesk\Autodesk Fusion 360\API\AddIns\LazyNest`

## Primeros pasos
1. Seleccionar piezas (o cargar proyecto).
2. Abrir la paleta **CA LazyNest**.
3. Definir material/stock, separación, opciones.
4. Anidar → revisar → **Aplicar** (CAM opcional).
5. ⓘ = info, diagnóstico, donación.
