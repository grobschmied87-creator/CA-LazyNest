# Kurzanleitung – CA LazyNest

## Voraussetzungen
- Autodesk Fusion (Windows empfohlen)
- Dieses Repo / ZIP entpackt

## Installation
1. Fusion **schließen**.
2. `INSTALL.bat` doppelklicken (oder `install.ps1` in PowerShell).
3. Fusion starten → **Dienstprogramme → Add-Ins → Scripts und Add-Ins**.
4. **LazyNest** markieren → **Ausführen** / automatisch starten aktivieren.

Pfad manuell: `%APPDATA%\Autodesk\Autodesk Fusion 360\API\AddIns\LazyNest`

## Erste Schritte
1. Bauteile im Design auswählen (oder Projekt laden).
2. Palette **CA LazyNest** öffnen.
3. Rohteil/Material, Abstand, Optionen setzen.
4. Nesten → Ergebnis prüfen → **Übernehmen** (optional CAM).
5. ⓘ = Info, Diagnose, Spendenhinweis.
