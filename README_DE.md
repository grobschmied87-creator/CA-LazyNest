# CA LazyNest

Fusion-360-Nesting-Add-in für Blech-/Plattenlayouts: Packen, Maserung, Rohteil-Bibliothek, optional CAM.

**Version:** 2.0.10 · **Lizenz:** MIT · Autor: Chris Adam / Chris Adam Modellbau

## Funktionen
- Nesting mit Abständen, Drehung/Maserung
- Rohteil-Vorlagen & Projekte speichern/laden
- UI DE/EN/ES/FR
- CA-Tools-Infobox (Theme, Diagnose, Spende)

Clipper-Geometrie; siehe `THIRD_PARTY` / Clipper-Lizenzen.

## Installation
Siehe [docs/QUICKSTART_DE.md](docs/QUICKSTART_DE.md) oder `INSTALL.bat` / `install.ps1`. Ziel:

`%APPDATA%\Autodesk\Autodesk Fusion 360\API\AddIns\LazyNest`

Nutzerdaten bleiben erhalten.
