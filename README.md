# CA LazyNest

Fusion 360 nesting add-in for sheet/part layouts: packing, grain, stock library, optional CAM hand-off.

**Version:** 2.0.10 · **License:** MIT · Author: Chris Adam / Chris Adam Modellbau

## Features
- Nesting with spacing, rotation/grain options
- Stock templates & project save/load
- Multi-language UI (DE/EN/ES/FR)
- Shared CA Tools shell (theme, diagnostics, donate info)

Clipper-based geometry; see `THIRD_PARTY` / clipper licenses in the tree.

## Install
See [docs/QUICKSTART_EN.md](docs/QUICKSTART_EN.md) or run `INSTALL.bat` / `install.ps1` (Fusion closed). Target:

`%APPDATA%\Autodesk\Autodesk Fusion 360\API\AddIns\LazyNest`

Keeps `user_prefs.json`, `user_stock.json`, `projects/`, `logs/`.
